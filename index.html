Shadowrocket & Happ Plus · macOS

Block internet access outside the VPN

Check the firewall and allowed tunnel from the menu bar. The system service keeps protection on when the selected VPN client is closed.

Get started

Get started

On an Apple Silicon Mac running macOS 13 or later, download the ARM64 disk image from GitHub Releases. Open it, drag the app to Applications, eject the image and launch the app from Applications. Intel users can build the universal app from source.

To package a development build identified by its source commit, run ./build-dmg.sh with Xcode Command Line Tools and Python 3 installed.

Turn on protection

  1. On first launch, select Shadowrocket or Happ Plus in VPN Server and enter its numeric IPv4 address and port. Choose TCP or UDP and click Apply. Existing installations keep their saved VPN server.
  2. Use the same numeric IP in the selected client’s server address and keep the original TLS SNI or Host. For Shadowrocket, select Global Routing → Proxy. Connect the selected client.
  3. Open VPN Kill Switch and authorize it to read the pf rules.
  4. Install the selected VPN client and connect it before enabling protection. You can remove protection offline. Removal keeps the applied client and VPN server for the next Install Kill Switch… action. Click the menu bar icon and choose Install Kill Switch… when protection is off. When protection is on, the same item becomes Remove Kill Switch…. It is hidden while protection status is unknown.

Update an existing installation

Quit the menu bar app and reopen the new build. Existing installations keep Shadowrocket and its server. The first protected Apply upgrades the old system service. For a manual reinstall, connect the selected client and use the new installer. The installer preserves the saved VPN server and attempts to restore the previous configuration if the update fails.

Read the menu bar icon

A checkmark means protection is on and the allowed tunnel matches the selected profile. A closed padlock inside the arch means the VPN is disconnected and only the configured exceptions are available. A stop sign inside the arch means protection is off.

An exclamation mark means the tunnel needs attention. A question mark means the status is unknown. Three dots indicate an operation in progress. The Protection row names the state. A green dot means the tunnel is allowed, orange means internet access is blocked or limited to direct exceptions, red means protection needs attention, and gray means protection is off or its state is unknown. During an operation the row reads Protection: Working…. Open the submenu for the VPN connection and external IPv4. Hold Option to see the allowed tunnel and last check time. Opening Protection checks the public IPv4 seen by ifconfig.co and internet-lab.ru over the current route. External RU IPv4 appears only when both checks succeed and the Russian site sees a different address. Click either address to copy the IPv4 as plain text. Each flag comes from the local GeoIP database for the displayed address. While the submenu is open, checks run at most once a minute. A blocked connection shows “Blocked”. If the service cannot be reached, the row shows “Unavailable”. In Settings → GeoIP, click Download Database to add a country flag beside the external IPv4. The default source is Loyalsoldier’s V2Ray geoip.dat. You can enter another HTTPS URL for a compatible database. Hover over the flag for the country name and code. Without a match, the row shows just the IP. The database card shows the installed file size, source URL and last successful update in local time. Click Update Installed Database to update from the installed source. Download Database fetches from the URL in the field each time, including when the installed database uses the same URL. Updates are manual, and a failed update keeps the previous database. Choose About to open a separate window with the build identifier and Open Guide. The app checks the firewall immediately after you install or remove protection or apply a server change. Connecting or disconnecting the selected client also triggers a check. If the selected VPN client shows Connected while the allowed tunnel is still none, the monitor rechecks at three-second intervals, up to three times. The green status returns once pf confirms the connected tunnel. Between changes, status refreshes every 30 seconds.

Terminal commands

On this Mac, the commands are in ~/.local/bin and can run from any directory. Each link opens the corresponding standalone script.

vpn-ks-check
Check live firewall rules, VPN status and the allowed tunnel.
vpn-ks-install
Install the rules and start the system service at boot.
vpn-ks-remove
Remove the service and restore direct internet access.

How protection works

VPN disconnected

The firewall allows the configured VPN server, DHCP and local loopback on lo0. It also allows destinations in the optional direct IPv4 list. Other traffic stays blocked.

VPN connected

About every five seconds, the service checks the active profile against the firewall rules. The local.shadowrocket-guard/tunnel anchor allows the active utun interface. Its number can change after a restart.

If the guard loses its place in the root ruleset or its base rules change, the service restores its rules and retries any pending connection-state cleanup.

Switch clients or servers

Open Settings… → VPN Server. Choose Shadowrocket or Happ Plus and enter the server IPv4 address, port and transport (TCP or UDP). Settings remembers each client’s fields as you type, including after relaunch or removal of protection. Apply switches the client and server together. If the selected client is disconnected, internet access stays blocked until its tunnel connects. Protection stays active and the change takes effect without a rebuild. You can correct the VPN server offline in the same window.

Profile, server address and restart check

The app detects a single enabled profile for the selected VPN client on this Mac. If the profile is missing, connect that client once and check scutil --nc list.

Direct IPv4 exceptions

Open Settings → Exceptions, enter an IPv4 address, CIDR or wildcard such as 192.168.* in the field below the table, then press Return or click + to its right. Click an address to edit it in place. Return accepts the edit and Escape cancels it. Select rows and click − to delete them. Apply saves the list and updates active protection. A list containing 0.0.0.0/0 requires explicit confirmation because it allows all IPv4 traffic outside the VPN. Listed destinations can use Wi-Fi or Ethernet even when the VPN is disconnected. Localhost is always allowed.

Restore connectivity

Run vpn-ks-check. With protection on and the VPN disconnected, expect Protection: on. and Allowed tunnel: none. Exit code 0 means the rules and profile agree, 1 means protection is off, and 2 means the result needs attention. If the selected VPN client is connected, compare its interface with the allowed tunnel and check again in five seconds. To inspect the TCP connections used by Shadowrocket, run:

lsof -nP -a -c MacPacket -iTCP

Remove protection offline

Run the command below in a local Terminal. It removes the service and its rules so the Mac can go online without the VPN.

sudo /Library/PrivilegedHelperTools/local.shadowrocket-killswitch/remove

If the helper is unavailable, run /bin/sh Commands/remove-shadowrocket-killswitch.command from the project root.
